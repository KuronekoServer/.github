## KuronekoServer
私たちは学生の頃からインターネットを通じて交流を深め、現在に至るまでインターネットサービス事業を行っている任意団体です。
<br><br>
### 目標
1. 無料/低コスト
> 予算や経費を圧縮することで、製品やサービスの提供にかかる費用を最小限に抑えています。Discord読み上げBOTなど全てのサービスを基本無料でご利用頂けます

2. 安定性
> 定期的なインフラの改定を行うことで安定性を高めています

3. 使いやすさ
> サービスの使用感向上のため、ユーザーの皆様のニーズを考慮した開発を行っています

当組織は2018年6月11日に設立され、2021/07/20にDiscordサーバーを開設しました。<br>
利用者様や寄付をしてくださった皆様には本当に感謝しています。おかげさまで現在も運営を続けております。<br>
改めまして、これからもKuronekoServerをよろしくお願いします。<br>
